# Homebrew Tap for yggdrion

This is a [Homebrew](https://brew.sh) tap containing casks for applications developed by yggdrion.

## Installation

To add this tap and install applications:

```bash
# Add the tap
brew tap yggdrion/tap

# Install Gote
brew install --cask gote

# Install gotree
brew install --cask gotree
```

## Available Casks

### Gote
A secure note-taking application built with Wails.

- **Description**: Password-protected encrypted note storage with real-time Markdown preview
- **Homepage**: https://github.com/yggdrion/gote
- **Installation**: `brew install --cask gote`

### gotree
A k9s-style TUI for many git repos and their worktrees.

- **Description**: Terminal UI to browse and manage multiple git repositories and their worktrees
- **Homepage**: https://github.com/yggdrion/gotree
- **Platforms**: macOS and Linux (arm64, amd64)
- **Installation**: `brew install --cask gotree`

## Usage

After installation, you can:

- Launch Gote from Applications folder or Spotlight
- Run `gotree` from your terminal
- Update an app: `brew upgrade --cask gote` or `brew upgrade --cask gotree`
- Uninstall an app: `brew uninstall --cask gote` or `brew uninstall --cask gotree`

## Development

This tap follows Homebrew's cask formula conventions. Each cask is stored in the `Casks/` directory with a `.rb` extension. `gotree.rb` is generated by GoReleaser on each release and should not be edited by hand.
